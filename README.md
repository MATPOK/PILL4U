# PILL4U - Twój asystent zdrowia

Aplikacja mobilna wspierająca regularne przyjmowanie leków, zaprojektowana z myślą o maksymalnej dostępności i prostocie obsługi.

## 🚀 O projekcie
PILL4U to projekt studencki realizowany w ramach zajęć z programowania. Aplikacja pozwala na zarządzanie harmonogramem leków, wysyłanie powiadomień oraz śledzenie postępów w leczeniu, również w trybie offline.

## 🛠 Stack technologiczny
* **Frontend:** Flutter (Dart)
* **Backend:** Node.js (Express)
* **Baza danych:** SQLite
* **Dokumentacja:** Markdown
